# E-Commerce Business Analytics & Customer Intelligence

An end-to-end e-commerce analytics project using **Python, MySQL, SQL, and Power BI** to analyze customer behavior, sales performance, payment methods, order status, and delivery performance.

## Project Overview

This project focuses on analyzing the Brazilian Olist e-commerce dataset to generate meaningful business insights. It combines Python-based data exploration, MySQL database management, SQL analysis, and an interactive Power BI dashboard.

The goal is to understand business performance, identify customer purchasing patterns, and support data-driven decision-making.

## Tools & Technologies

- **Python:** Data cleaning, data exploration, and feature engineering
- **Pandas & NumPy:** Data manipulation and analysis
- **Matplotlib & Seaborn:** Data visualization
- **MySQL:** Database creation, data storage, and management
- **SQL:** Business analysis and insight generation
- **Power BI:** Interactive dashboard development
- **Jupyter Notebook:** Analysis environment

## Dataset

The project uses the Brazilian E-Commerce Public Dataset by Olist.

The dataset contains approximately 1.55 million records across 9 CSV files, covering:

- Customers
- Orders
- Order Items
- Order Payments
- Order Reviews
- Products
- Sellers
- Geolocation
- Product Category Translation

## Project Workflow

1. **Data Understanding & Quality Audit**
   - Dataset profiling
   - Missing value analysis
   - Duplicate and key checks
   - Referential integrity checks
   - Order lifecycle validation

2. **Python Data Analysis**
   - Data cleaning and exploration
   - Customer and sales analysis
   - Feature engineering
   - Data visualization

3. **MySQL Database**
   - Database and table creation
   - Importing datasets into MySQL
   - Establishing table relationships

4. **SQL Business Analysis**
   - Monthly sales analysis
   - Customer repeat purchase analysis
   - Product category performance
   - Payment method analysis
   - Delivery performance analysis
   - Customer segmentation

5. **Power BI Dashboard**
   - Monthly Sales Trend
   - Top 10 Product Categories by Revenue
   - Payment Value by Payment Method
   - Order Status Distribution
   - Delivery Performance
   - KPI Cards and interactive Year/Month slicers

## Key Business Insights

- Total item sales were approximately **R$ 13.59 million**, excluding freight.
- The dataset contains **96,096 unique customers**.
- Approximately **3,099 customers** made repeat purchases.
- Credit card was the most frequently used payment method.
- Approximately **91.9% of delivered orders** were delivered on time or early.
- Health & Beauty was the highest-revenue product category in the analysis.
